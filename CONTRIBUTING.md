## 👥 Contribution

Contributions to this repository are welcome! If you have notes, study materials, or resources that could benefit other BECE students, please consider contributing to this repository.

To contribute:
1. 🍴 Fork the repository
2. ➕ Add your materials to the appropriate semester and subject folder
3. 🔄 Create a pull request

> 💡 The repository is large (several GB). You don't need to clone it — open the right folder on GitHub and use **Add file → Upload files** to add your notes and open a pull request from there.

### 🏅 Getting listed as a contributor

- **Any contribution is welcome.** Once your pull request is merged, you automatically appear in the repository's contributors on GitHub.
- **To be listed on the website's Contributors page** ([notes.arpanadhikari7.com.np](https://notes.arpanadhikari7.com.np/)), contribute at least **10 relevant study note files** (notes, question papers, lab reports and similar). Contributions across several pull requests add up.
