# 📚 BECE Vault

Study notes for the Bachelor of Engineering in Computer Engineering (BECE) program at Pokhara University, Nepal: lecture notes, past questions, lab materials and syllabus for every semester. All credit goes to the people who created these notes.

## 🌐 Study on the website

### 👉 [notes.arpanadhikari7.com.np](https://notes.arpanadhikari7.com.np/)

Everything in this repository is on **BECE Vault**, the companion website, and that is where all the details now live: semesters, subjects, course codes, credits, syllabus and the notes themselves. This repository is several GB, so please study from the site rather than cloning or downloading it.

### How to use the site

1. **Pick a semester** on the home page (or Electives), then a subject.
2. **Choose a file** from the list on the left. PDFs open right in the browser: search, zoom, go to a page and highlight.
3. **Download** any file with one click to study offline.
4. Use the **CGPA Calculator** to work out your SGPA/CGPA with every subject's credit hours.
