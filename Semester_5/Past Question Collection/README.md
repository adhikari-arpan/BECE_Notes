# Past Question Collection: Semester V

Past **Pokhara University exam papers** for Semester V, one folder per subject. This collection is
still small, so every paper you add helps the next batch. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to send files.

## Where to put a paper

```text
Semester_5/Past Question Collection/
├── <Subject Name>/
│   └── 2025_Fall_PNS.pdf                 ← exam papers, named as below
└── College Assessments/
    └── 2024_College_Assessments/          ← one folder per year: all-college / internal assessment papers
```

## File name: `Year_Spring/Fall_ShortForm`

- **Year** is when the exam was held, in AD (e.g. `2025`).
- **Spring** or **Fall** is the exam term.
- **ShortForm** is the subject's short form from the table below, e.g. `2024_Spring_AG.pdf`.
- **College assessments** (internal exams, all-college assessments) go in `College Assessments/<Year>_College_Assessments/`,
  e.g. `College Assessments/2024_College_Assessments/`. Name each file after its subject.
- Use one file per paper, PDF preferred. Scan it clearly (see the scanning checklist in CONTRIBUTING.md).

| Folder | Short form | Example file name |
|---|---|---|
| `Probability and Statistics/` | `PNS` | `2025_Fall_PNS.pdf` |
| `Embedded System/` | `ES` | `2025_Fall_ES.pdf` |
| `Engineering Management/` | `EM` | `2025_Fall_EM.pdf` |
| `Artificial Intelligence/` | `AI` | `2025_Fall_AI.pdf` |
| `Digital Signal Analysis and Processing/` | `DSAP` | `2025_Fall_DSAP.pdf` |
| `Software Engineering/` | `SE` | `2025_Fall_SE.pdf` |

Electives: use the elective's short form, e.g. `2025_Spring_BDT.pdf` for Big Data Technologies.

Folders follow the before-2025 semester order. Papers from the 2025 curriculum go in the same subject's folder,
wherever that subject is listed here.

> Empty folders hold a `.gitkeep` placeholder. When you add the first paper to a folder you can delete it.
