# Past Question Collection

Past **Pokhara University BE Computer Engineering exam papers**, kept separate from the notes: one folder per
semester, and inside it one folder per subject. This collection is still small, so every paper you add helps the
next batch. See [CONTRIBUTING.md](../CONTRIBUTING.md#past-question-papers) for how to send files.

```text
Past Question Collection/
├── Semester_1/
│   ├── README.md                    ← subject folders, short forms and example file names
│   ├── Programming in C/
│   │   └── 2024_Fall_C.pdf
│   └── College Assessments/
│       └── 2024_College_Assessments/
├── Semester_2/
└── ...
```

- **File name:** `Year_Spring/Fall_ShortForm`, e.g. `2024_Spring_AG.pdf`. Each semester's README lists the short forms.
- **Formats:** PDF or image (`.pdf`, `.jpg`, `.png`). A PDF under 5 MB, an image under 1 MB.
- **College assessments** go in `Semester_N/College Assessments/<Year>_College_Assessments/`.

On the website: [Past Questions](https://notes.arpanadhikari7.com.np/past-questions).
